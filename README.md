# Angels' Time 🕊️

Современное веб-приложение для отслеживания времени намаза и чтения Священного Корана в нежной пастельной палитре **Material You**.

## ✨ Особенности

- ⏱ **Точное расписание намазов**: автоматический расчёт времени (Фаджр, Восход, Зухр, Аср, Магриб, Иша) по геопозиции или выбранному городу.
- 🔔 **Уведомления и Азан**: настройка звуковых оповещений и громкости азана.
- 📖 **Священный Коран**: чтение сур с арабским текстом (шрифт Amiri), транскрипцией и переводом, плавной навигацией и сохранением прогресса.
- 🎨 **Material You дизайн**: нежная пастельно-розовая палитра, гармоничные тональные переходы, поддержка светлой и тёмной темы.
- 📱 **PWA & Мобильная адаптация**: оптимизировано под смартфоны, планшеты и десктопы.

## 🌐 Автоматическая публикация на GitHub Pages

В репозитории уже настроен **GitHub Actions workflow** (`.github/workflows/deploy.yml`), который автоматически собирает и публикует сайт при каждом `git push` в ветку `main` или `master`.

### Как опубликовать проект:

1. **Создайте репозиторий на GitHub** (если ещё не создан).
2. **Инициализируйте git и отправьте код**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<ваш-username>/<имя-репозитория>.git
   git push -u origin main
   ```
3. **Включите GitHub Pages через GitHub Actions**:
   - Перейдите в ваш репозиторий на GitHub.
   - Откройте вкладку **Settings** (Настройки).
   - В левом меню выберите **Pages**.
   - В разделе **Build and deployment** -> **Source** выберите **GitHub Actions**.
4. **Готово!**
   - GitHub Actions автоматически запустит сборку во вкладке **Actions**.
   - Через 1–2 минуты ваш сайт будет доступен по адресу:
     `https://<ваш-username>.github.io/<имя-репозитория>/`
